# Mobile Shop Excel Data Analysis

A hands-on Excel data analysis project based on mobile shop
sales and employee data.

## Tools Used

- Microsoft Excel

## Topics Covered

- Excel Formulas
- IF and Nested IF
- SUM
- SUMIF
- SUMIFS
- COUNTIF
- VLOOKUP
- MOD
- MAX
- MIN
- Percentage Calculations
- Pivot Tables
- Pivot Table Filters
- Charts and Data Visualization
- Sales Analysis
- Employee Attendance Analysis
- Quarterly Sales Analysis

## Analysis Performed

- Product-wise sales analysis
- Product-wise order analysis
- Company-wise product analysis
- Employee attendance analysis
- Department-wise attendance
- Department-wise sales
- Gender-wise sales
- Employee count by department
- Customer-wise sales
- Sales channel analysis
- Quarterly sales analysis
- Salary analysis and grading
